# OpenKern — Logo Exploration (creative directions)

> Mission §9 · brandbook-master Etapa 1
> Five distinct directions. Required coverage present: technical, premium-institutional,
> developer/neutral, high-impact-gradient, minimal-terminal.
> All drafts. No final assets until one direction is approved (Etapa 3 / mission §33).

**Color constraint (§11):** OpenKern must NOT reuse sibling palettes —
SE7EN PAY cyan `#00E9F4`, EPISTEMOS indigo/amber, NOMOS / CONFRAPAG neon-green
`#5AF78E`/`#15F35B`. Directions steer into amber/brass, arc-blue, violet→orange, and
neutral graphite territory that none of the siblings own.

---

## A — Kernel Core  *(technical / systems, flat)*
- **Concept:** A kernel is a protected core inside a boundary. The mark is that literally:
  a solid inner core nested in an outer ring that is broken by exactly one gate — the
  only way through is an explicit opening.
- **Symbol:** concentric rounded-squares; solid core; outer boundary with one gate notch.
- **Feel:** precise, protected, deterministic, low-level.
- **Colors:** Graphite `#0A0E14`, Ink `#EAF0F8`, Signal Amber `#F0A63C`, Neutral `#8A97AB`.
- **Type:** Space Grotesk / Geist for wordmark; JetBrains Mono for system voice.
- **Risks:** concentric shapes can read "target"/"aperture" (camera) if the gate is weak.
- **Best for:** infra docs, CLI, architecture diagrams, dense dashboards.

## B — Capability Gate  *(premium / authority, flat)*
- **Concept:** Authority as a seal. A hexagonal seal with a single slot — nothing passes
  except through the declared aperture. Reads as permission, not decoration.
- **Symbol:** hex seal with a gap/slot; an implied K in the negative space.
- **Feel:** authority, sealed, deliberate, institutional, premium.
- **Colors:** Near-black `#0B0B0D`, Bone `#F1EEE7`, Brass `#C9A35B`, Slate `#6E6A63`.
- **Type:** Fraunces (display, restrained) + Geist body + JetBrains Mono.
- **Risks:** brass + hex can drift toward crypto/finance clichés if over-styled.
- **Best for:** governance/enterprise decks, security page, letterhead, print.

## C — OK Monogram  *(developer / neutral, flat, grid-built)*
- **Concept:** A geometric monogram from O + K. The O is a kernel ring; the K's diagonal
  doubles as an execution vector leaving the core.
- **Symbol:** ring (O) fused to a two-stroke K whose lower leg is an arrow/vector.
- **Feel:** engineered, clean, systematic, developer-first, neutral.
- **Colors:** Ink `#101418`, Paper `#F7F8FA`, Arc Blue `#2E6BFF`, Graphite `#5A6472`.
- **Type:** Geist / Inter for wordmark; JetBrains Mono for code.
- **Risks:** monograms are a crowded space; must be unmistakably O+K, not a generic K.
- **Best for:** avatar, favicon, app icon, GitHub, developer-facing everything.

## D — Execution Trace  *(high-impact, gradient)*
- **Concept:** A governed nucleus emitting paths — some solid (ALLOW), some dashed (ASK),
  one severed (DENY). Governance rendered as controlled radiance.
- **Symbol:** core node with radiating governed paths; single gradient sweep.
- **Feel:** energetic, modern, orchestration, motion, standout.
- **Colors:** gradient Violet `#7A5CFF` → Signal Orange `#F0603C` over Void `#0A0912`; Ink `#F2EEFA`.
- **Type:** Space Grotesk display + Geist + JetBrains Mono.
- **Risks:** gradient must survive 16 px mono and single-color print — mono proof required.
- **Best for:** hero, social preview, launch art, motion.

## E — Boundary Mono  *(minimal / terminal)*
- **Concept:** One monoline glyph: a bracket enclosing a core, `[•]` — kernel boundary
  and terminal prompt in a single stroke. Honest, unix, quiet.
- **Symbol:** single-weight bracket-pair around a dot/core; optional caret fusion.
- **Feel:** unix, terminal, honest, minimal, engineering.
- **Colors:** Terminal `#0C0F0E`, Near-white `#E9EDEA` (not phosphor-green), Deny-red `#D64541` (state only).
- **Type:** JetBrains Mono throughout (mono-as-identity) + Geist for long body.
- **Risks:** minimalism can read "unfinished" without a rigorous grid and spacing.
- **Best for:** terminal, README badges, stickers, dotfiles crowd.

---

### Recommendation for the owner
**A — Kernel Core** as primary, with **C — OK Monogram** as the avatar/favicon partner
(mark systems often pair a conceptual symbol with a monogram at tiny sizes). **B** is the
premium alternate for governance/enterprise contexts. **D** and **E** are held as the
expressive and the minimal poles. Final selection is the owner's (mission §33).
